Text snippets in KDE with and without Klipper [Update #2, “Solved”]

Published onAugust 31, 2011by alex77

I too had reached a point of frustration where I started looking for ways to avoid having to type the same text over and over again. For example, the ever-popular " Dear Sir or Madam, ". I wanted a faster and more convenient solution.

I'm currently using KDE and there are two possible solutions.1)

The KDE Control Center has shortcuts and gesture controls , where you can also define your own shortcuts. You then assign a "shortcut" (i.e., a key combination, e.g., Meta+Alt+1) to these shortcuts, and pressing this key combination will insert the text.



However, as you can see from the screenshot , this is rather unsightly. To have "Dear Sir or Madam" entered, you have to enter:

Shift+S:E:H:R:SPACE:G:E:E:H:R:T:E:SPACE:SHIFT+K:U:N:D:I:N:,:RETURN:Shift+S:E:H:R:SPACE:G:E:E:H:R:T:E:SPACE:SHIFT+K:U:N:D:E:,:RETURN:RETURN

Urks.

But it works directly and everywhere…

2)

Klipper . Klipper can be configured to perform certain actions when text matching a regular expression is copied to the clipboard.

The screenshots above show how I configured Klipper so that it works (for me!) .

  • Action properties
    • Regular expression: ^,,,
    • Command: /home/ask/bin/Klipper-Replace-Text %s
    • Output handling: Replace clipboard

This means that when text is copied to the clipboard that begins with “ ,,, ” (3 commas), the Klipper-Replace-Text script is called and receives whatever was copied as a parameter.

In simple terms, the Klipper-Replace-Text script cuts off the prefix (,,,), then looks up the short text (e.g., " SgDuH ") in a "database" and copies the corresponding long text (e.g., " Dear Sir or Madam, ") to the clipboard.

The script is available in a nicely formatted version on pastebin: http://pastebin.com/XNAfyrJN ; it requires a "database" (text file), for example this one: http://pastebin.com/C6yUgSx0

Update:

2 "little things" forgotten:

  1. By default, Klipper solution (2) won't work. The reason is that KDE (at least on my openSUSE 11.4) is shipped with Klipper configured to *NOT* match with netscape/firefox/browser windows. You first have to remove the rule "netscape:browser" (or something similar...) from Klipper's "Advanced" settings. Then it works, BUT ...
  2. If you do that, you'll get these pop-ups all the time, for example, when you select URLs (in the address bar). It gets *MEGA* annoying in the long run! Which is probably also why KDE is configured so that Firefox Klipper stays silent…

Update #2, Solution!:

I've been working on it a bit more. As described above, I've now disabled automatic action triggering for Firefox (the WM_CLASS to use can be found using xprop WM_CLASS ). However, there's the global shortcut Ctrl+Alt+R , which triggers an action manually!

And that's how I'm using it now 🙂 So, my Klipper-Replace-Text script, which is triggered by “,,,”, but not automatically by browsers.

Do it for me 😉


$HOME/bin/Klipper-Replace-Text Script:

#! /bin/bash

# Replace the text passed from the clipboard with
# a new text.
# Example: Change "SgDuH" to "Dear Sir or Madam"

# File containing the short and long texts
replace_db="$HOME/var/klipper-replace-text.txt"

# The script is called by Klipper when any prefix
# was copied to the clipboard. This prefix should be removed.
prefix=",,",

# Fetch:
# qdbus org.kde.klipper /klipper org.kde.klipper.klipper.getClipboardContents
# Set:
# qdbus org.kde.klipper /klipper org.kde.klipper.klipper.setClipboardContents Klipper replace text

# Was text passed on the command line?
if [[ "$#" -eq 0 ]]; then
  # Retrieve text from clipboard
  clip=$( qdbus org.kde.klipper /klipper org.kde.klipper.klipper.getClipboardContents )
else
  # Take text from the command line
  clip="$@"
fi

# Remove prefix from clip
clip_clean=${clip#$prefix}
# Make the text "safe"
clip_quoted=$( printf "%q" "$clip_clean" )

# Search in the "database"
replace=$( awk -F'°' "/^${clip_quoted}/ "'{print $2}' "$replace_db" 2> /dev/null )

# What was found?
[[ -z "$replace" ]] && exit 1

# Expand any existing backslash sequences (\n -> line break)
replace_bs=$( printf "%b" "$replace" )

# Save to clipboard
qdbus org.kde.klipper /klipper org.kde.klipper.klipper.setClipboardContents "$replace_bs" > /dev/null 2>&1
printf "%s\n" "$replace_bs"

exit $?
# EOF #

$HOME/var/klipper-replace-text.txt Database:

Dear Sir or Madam,
Dear Customer,
as°Alexander Skwar
Dear Sir or Madam,\n\nBLAH\n\nSincerely,\n\nAlexander Skwar\n
mfg°\nSincerely,\n\nAlexander Skwar\n
bash°#! /bin/bash\n\n# This script does...\n\nexit 0\n# EOF #
